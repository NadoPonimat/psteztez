# Trackaer — нативная Android-версия (Kotlin + Jetpack Compose)

Полностью нативное переписывание трекера: без WebView, без JavaScript, без Capacitor.
Работает офлайн, запускается мгновенно, экраны переключаются без задержек.

## Что внутри

- **Kotlin + Jetpack Compose** (Material 3), один Activity, навигация Compose Navigation
- **Room** — локальная база данных с индексами и SQL-агрегатами (никаких «переиндексаций»)
- **DataStore** — настройки
- **WorkManager** — ежедневное напоминание
- **18 курсов, 841 урок (~700 часов)** — конвертированы из теории трекера в структурированные JSON-ассеты:
  каждый урок — 2 части с теорией, практикой с таймингом, шпаргалкой/дневником и проверочными вопросами
- **Заставка как в старой версии** — 10 вариантов анимации (Радар, Пульс, Скан, Рожки, Слух, Вспышка,
  Молния, Дождь, Трещина, Без анимации), своё фото фоном, длительность и показ заголовка —
  всё меняется в **Настройки → Анимация входа**, тапом пропускается
- **Люди и карта связей** — профили с полями и отношением, связи через общие признаки, пружинный граф на Canvas
- **Новости** — лента с настраиваемыми источниками
- **Обмен валют** — курсы Нацбанка РК + конвертер
- **Разговорник** — фразы по ситуациям и диалоги, с озвучкой (TTS)
- **Книги** — читалка с импортом своих файлов (TXT / FB2 / FB2.ZIP)
- **План занятий** — расписание учёбы; **словарь** — коробки Лейтнера

Экраны: Главная (сводка дня), Привычки (серии + 14-дневная шкала), Финансы (кошелёк/копилки/долги),
Тренировки, Учёба (план занятий, книги, слова, разговорник), Люди (профили + карта связей),
Новости, Курсы валют, Питание (ккал и БЖУ), Статистика (графики за 14 дней),
Курсы (каталог → курс → урок), Настройки (анимация входа, напоминание, цель калорий, валюта).

## Как получить APK

### Вариант 1 — через GitHub (автоматически)
1. Создай новый репозиторий (или замени содержимое существующего) и загрузи туда **все файлы этого проекта**.
2. GitHub Actions сам соберёт APK при пуше в `main`/`master` и выложит его в **Releases** с тегом `latest`.
3. Скачай `app-release.apk` из Releases и установи на телефон.

### Вариант 2 — Android Studio
Открой папку проекта в Android Studio (Hedgehog или новее), дождись синхронизации Gradle,
затем **Build → Build APK(s)**.

## Сборка из терминала

```bash
./gradlew :app:assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Нужны JDK 17+ и Android SDK (platform 35). В корне уже лежит `trackaer.keystore` — подпись
стабильна между сборками, поэтому обновление ставится поверх старого без удаления.

> ⚠️ Ключ подписи лежит в репозитории (пароль: `trackaer-2026`). Для личного приложения это
> удобно, но если репозиторий публичный — любой может собрать APK с той же подписью.
> При желании перенеси ключ в GitHub Secrets (`KEYSTORE_BASE64`) и добавь шаг расшифровки в workflow.

```
├── TrackaerApp.kt        — Application, база, канал уведомлений

├── vm/ViewModels.kt      — все ViewModel (MVVM)

│   ├── Nav.kt            — навигация + нижняя панель

app/src/main/assets/courses/ — 18 JSON-курсов (841 урок)
```

## Курсы

Исходная теория хранилась в `theory-*.js` старого приложения. Конвертер
(`scripts/convert_courses.mjs` в рабочей папке) разбирает их через Node.js и собирает
JSON-ассеты: курс → модули → уроки → секции (теория, практика, шпаргалка, самопроверка).
Чтобы обновить контент: поправь `theory-*.js`, перезапусти конвертер, скопируй JSON в `assets/courses/`.

## Данные старого приложения

Нативная версия хранит данные в своей базе и стартует с чистого листа.
Старое приложение (WebView-версия) остаётся на телефоне — данные можно подсмотреть там.
В будущем можно добавить импорт из старой базы.
