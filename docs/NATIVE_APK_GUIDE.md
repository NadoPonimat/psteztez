# Нативный APK PlayZone с уведомлениями Firebase (FCM)

Новая оболочка приложения: внутри тот же сайт CRM, но снаружи — настоящее
Android-приложение (Java + Firebase). Что это даёт по сравнению с TWA:

* при первом запуске Android показывает **стандартный системный запрос**
  «Разрешить приложению PlayZone отправлять уведомления?» — как у обычных
  приложений;
* уведомления идут **напрямую от Google (FCM)**, а не через Chrome —
  приходят даже когда приложение убито из памяти;
* звук и вибрация — свой канал уведомлений «Время вышло».

Собирается автоматически на GitHub — Android Studio не нужен.

---

## Шаг 1. Загрузить обновление на GitHub

1. Скачать `playzone-native.zip`, распаковать.
2. На GitHub открыть репозиторий → **Add file → Upload files**.
3. Перетащить **папку `android` целиком** (саму папку, как с prisma) —
   внутри окажутся `android/app/...`, `android/build.gradle` и т.д.
4. Файлы из распакованной папки перетащить по своим местам:
   * `prisma/schema.prisma`, `package.json`, `bun.lock`, `worklog.md` — в корень;
   * `src/...` — в существующие папки `src` (пути сохранятся);
   * `docs/NATIVE_APK_GUIDE.md` — в `docs`.
5. Workflow: открыть на GitHub папку `.github/workflows` → **Add file →
   Upload files** → перетащить `build-apk.yml` → Commit.
6. Vercel задеплоит изменения сам (проверь вкладку Deployments).

## Шаг 2. Firebase-проект (бесплатно, ~5 минут)

1. Открыть https://console.firebase.google.com → **Создать проект**
   (название любое, например `playzone`; аналитику можно отключить).
2. В проекте: шестерёнка ⚙️ → **Настройки проекта** → в разделе
   «Ваши приложения» нажать иконку **Android**.
3. **Имя пакета Android:** `com.playzone.crm` → **Зарегистрировать
   приложение** → **Скачать google-services.json**.
4. Загрузить этот файл на GitHub в папку `android/app/`: открыть
   `android/app` → Add file → Upload files → перетащить
   `google-services.json` → Commit.
5. Там же в Настройках проекта → вкладка **Учётные записи служб** →
   **Создать закрытый ключ** → скачается JSON-файл. Он нужен для шага 3.

## Шаг 3. Три переменные в Vercel

Из скачанного JSON сервис-аккаунта взять значения и добавить в Vercel
(проект → Settings → Environment Variables):

| Переменная | Значение из JSON |
|---|---|
| `FIREBASE_PROJECT_ID` | `project_id` |
| `FIREBASE_CLIENT_EMAIL` | `client_email` |
| `FIREBASE_PRIVATE_KEY` | `private_key` (целиком, как есть — с `\n`) |

После сохранения: **Deployments → Redeploy** (пересобрать проект).

## Шаг 4. Собрать APK на GitHub

1. Вкладка **Actions** → слева **Build APK** → **Run workflow** → Run.
2. Подождать 3–6 минут; клик по зелёному запуску → внизу **Artifacts** →
   скачать **PlayZone-APK** (zip внутри — сам `app-release.apk`).
3. Если сборка красная — открыть лог, текст ошибки прислать в чат.

## Шаг 5. Установить на телефоны

1. Перекинуть `app-release.apk` на телефон (Telegram/USB/облако).
2. Открыть файл → разрешить «установку из неизвестных источников».
3. При первом запуске появится системный запрос уведомлений — **Разрешить**.
   Это тот самый запрос, «как у обычных приложений».

Старое TWA-приложение можно удалить: это другое приложение (новое
называется `PlayZone`, пакет `com.playzone.crm`), данные CRM общие —
всё в облаке.

## Шаг 6. Проверка

1. Открыть приложение → сказать «установил» — сервер проверит, что FCM-
   токен появился в базе (таблица `FcmToken`).
2. Тест: запустить сеанс на 1 минуту → свернуть/убить приложение →
   через минуту (cron-job.org стучится каждую минуту) приходит
   системное уведомление «⏰ Время вышло!» со звуком и вибрацией.

---

## Если уведомления не приходят

| Симптом | Что делать |
|---|---|
| Приложение не спросило разрешение | Настройки → Приложения → PlayZone → Уведомления → включить; затем перезапустить приложение |
| Разрешение есть, но молчит | Проверить, что в Vercel заданы все 3 переменные FIREBASE_* и сделан Redeploy |
| Xiaomi/Redmi/Huawei/Honor | Настройки → Приложения → PlayZone → Экономия батареи → «Без ограничений»; Автозапуск → Вкл |
| Телефон Huawei без сервисов Google | FCM недоступен — используйте прежний способ (кнопка Web Push в браузере/TWA) |
| Сборка в Actions красная | Прислать текст ошибки из лога |

## Технические детали

* Отправка: `/api/push/tick` (cron-job.org, каждую минуту) → находит
  сеансы `ACTIVE` с вышедшим временем и `pushedAt = null` → шлёт **и**
  Web Push (для браузеров/TWA), **и** FCM (для нативного APK) → ставит
  `pushedAt` (один сеанс = одно уведомление).
* Токены телефонов: таблица `FcmToken` (регистрация самим приложением
  на `POST /api/push/register-fcm`).
* Подпись APK: `android/app/playzone.keystore` (PKCS12, alias `playzone`,
  пароль `PlayZone2024`) — лежит в приватном репозитории, чтобы все
  сборки имели одинаковую подпись и обновления ставились «поверх».
  Если репозиторий станет публичным — перевыпустить ключ.
* Новая версия приложения: поднять `versionCode` в `android/app/build.gradle`.
